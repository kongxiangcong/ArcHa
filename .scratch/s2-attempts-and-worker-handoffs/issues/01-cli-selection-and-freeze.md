# 01: 通过环境配置选择并冻结 CLI

**What to build:** 用户通过现有执行环境配置明确选择 Codex CLI 或 DSH CLI，准备、执行与终验使用正确的角色配置；历史 Run 恢复保持原后端和实际配置。

**Blocked by:** None (can start immediately).

**Status:** claimed

**Spec:** [S2 实现规格](../spec.md)

- [ ] 复用既有配置入口，统一准备、Expert、Designer、Reviewer 的后端解析，区分后端类型、安装定位与模型/provider 参数，保持角色参数隔离。
- [ ] 合同未明确限制后端时，允许环境选择在同一 revision 的新 Run 生效；合同显式限制与选择冲突时报错，不暗中覆盖目标、权限或冻结策略。
- [ ] 新 Run 保存实际解析配置及来源；恢复使用原配置并核对必要兼容条件，不因 PATH、本机默认值或环境修改悄悄换工具或模型。
- [ ] 启动前选择后端，无自动路由、失败自动换 CLI 或原 Run 热切换；缺工具等真实失败带上下文报告。
- [ ] 观察入口能显示实际角色后端与来源，查看状态不触发模型或改变控制意图。
- [ ] 通过现有准备/启动/恢复入口验证角色隔离、配置冲突和新默认值不影响旧 Run；配置测试不启动真实 DSH、不新增 DSH 专用测试。
- [ ] 必要调整在现有配置与适配器入口完成，替代后清理无调用旧选择路径，不建立第二套配置系统。

本票交付后端选择和冻结。显式切换后的预算重置与会话接入由 05 交付，不在本票重复实现。
