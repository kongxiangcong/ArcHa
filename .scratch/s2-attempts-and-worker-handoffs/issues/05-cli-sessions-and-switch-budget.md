# 05: 双 CLI 会话恢复与切换后的预算重置

**What to build:** 用户能以配置选定的 CLI 续接 Run 专家会话或从材料重建；明确换 CLI 启动新 Run 时获得新的执行额度，同时保留历史用量。Codex 完成必要验证，DSH 按当前条件先交付实现。

**Blocked by:** 01 — CLI 选择与冻结；03 — Run 专家与反馈；04 — 在途控制。

**Status:** resolved

**Spec:** [S2 实现规格](../spec.md)

- [x] Codex 与 DSH 均接入统一派发、结果、错误、用量和控制语义；各自 CLI 参数与输出在适配器内处理，Call ID 与原生会话身份分离。
- [x] 同后端用明确会话身份续接 Expert，保持稳定材料入口与必要 cwd/权限条件，不按最近会话猜测；Designer 默认按工作独立上下文，无空闲常驻进程。
- [x] 会话确实不可续接时记录原因并从该 Run 材料重建；区分后端故障、会话丢失和已执行但终态未知，不能用重建掩盖未知执行并重发。
- [x] Codex 采用本次调用的可靠终态与实际用量；DSH 实现会话采用、当前调用最终结果及用量解析，明确启动未成功与计量未知的差别。
- [x] 两后端实现 pause/stop 控制契约，保留中断日志/成果与未知项；不自动改用另一 CLI，不把原生 session 跨后端复用。
- [x] 仅用户明确切换 CLI 并创建新 Run 时，新 Run 的时间及已配置 token 执行额度从零扣减；合同未限制后端可保持 revision，旧 Run 保持原配置。
- [x] 历史实际用量与本次额度起点可区分；普通暂停、重启、失败重试或仅新建 Run 不重置，项目总额硬限制仍有效，不清空账本。
- [x] 默认时间额度 7200 秒、token 无上限，显式限制继续有效；并行耗时仍逐调用/评价累加，三个各十分钟扣减三十分钟，在途暂停等待也计实际耗时。
- [x] 以可控引擎/配置/计量夹具验证额度起点、并行计时、未知计量和重复恢复；真实 Codex 小任务验证续接或有原因重建、终态、取消及跨进程恢复，记录版本与必要证据。
- [x] DSH 当前仅实现：不新增专用测试，不安装、登录或运行真实 DSH；已有回归不无故删除，交付明确“已实现、未运行验证”。该限制不扩大为免除 Codex 或公共逻辑测试。
- [x] 观察结果显示实际 CLI、Call/session、预算起点/消耗与未验证范围，清理被替代的新会话或独立计量路径，不制造第二套状态或预算账。

本票按用户要求合并原 05（Codex）、06（DSH）和 07（预算），DSH 环境缺失不作为本票不可验收的条件，但不得宣称双 CLI 均已实测通过。
