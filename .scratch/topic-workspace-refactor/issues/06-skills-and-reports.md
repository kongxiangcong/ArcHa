# 06: 贯通研究技能与按需报告

**What to build:** 用户通过研究技能在目标工程初始化、澄清目标、运行或继续探索，并在需要时整理已有材料生成叙事报告，无需全局安装或强制依次调用四个技能。

**Blocked by:** 04：停止、人工修改与安全继续；05：按轮数推进探索、处理阻塞并完成收尾

**Status:** ready-for-agent

依据：[父规格](../spec.md)、[开发方案](../../../archa-refactor-plan.md)、[架构决策](../../../docs/adr/0001-topic-workspace.md)。具体文件清单以开发方案为准。

**范围与归属：** 负责四个技能及其脚本、安装与项目布局工具、部署资源和日志整理消费者的迁移。将 04 与 05 的控制和预算能力贯通，具体技能说明按相应写作规范更新。

- [ ] 初始化技能生成新专题；任务技能支持目标与问题队列调整及 Worker 配置检查，不再编译冻结契约。
- [ ] 循环技能实际调用本地运行时的运行/继续能力，停止与追加预算使用既定协议，汇报研究完成、阻塞或剩余缺口而不伪称交付成功。
- [ ] 明确目标可直接初始化并运行，不要求用户依次调用四个技能；已完成专题和实质换题遵守既定边界。
- [ ] 日志整理从新专题材料生成按需叙事报告，不依赖旧账本、旧 Worker 或 Reviewer，也不在每轮自动生成报告。
- [ ] 必要原件与脚本可留存，既有原件直接引用；报告是衍生展示，不影响状态推导，不创建第二份权威认知状态。
- [ ] 运行时部署清单为单一来源；本地入口、日志整理及全部实际依赖和模板均在目标工程可用，不依赖开发仓库或全局安装。
- [ ] 技能脚本、安装器和布局工具不再把新调用指向旧运行时；保留旧研究数据，不尝试迁移或继续执行。
- [ ] 在独立目标工程完成技能安装/部署和初始化→运行→停止→人工修改→继续→按需报告的集成验证；同步当前技能入口说明。
