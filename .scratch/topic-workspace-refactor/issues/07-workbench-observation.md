# 07: 在工作台查看专题与实时执行

**What to build:** 用户在浏览器中浏览新专题的认知状态、轮次材料和真实运行活动，调用未结束时也能看到日志，停止后仍能查看现场。

**Blocked by:** 04：停止、人工修改与安全继续；05：按轮数推进探索、处理阻塞并完成收尾

**Status:** ready-for-agent

依据：[父规格](../spec.md)、[开发方案](../../../archa-refactor-plan.md)、[架构决策](../../../docs/adr/0001-topic-workspace.md)。具体文件清单以开发方案为准。

**范围与归属：** 负责观察后端、前端 API 客户端与类型、专题/轮次视图、材料阅读、日志展示及新格式 demo。以专题身份替代旧 Run 视图；控制操作在 08 接入。

- [ ] 前后端使用一致的新观察契约，专题列表和详情来自新工作区，不为兼容旧 Run/request 历史而制造伪身份或审计记录。
- [ ] 仅显示 Expert、Executor 与收尾活动，移除旧角色固定栏目与 designer 分支判断；轮次详情和导航真实可用。
- [ ] 展示当前角色、轮次、开始时间、持续时间和流式 stdout/stderr；调用尚未结束时能看到新输出，不解析私有工具事件或猜测模型行为。
- [ ] 运行中、停止中、空闲、未知执行与专题状态分开显示，失败和中断保留已有日志，收尾日志与探针生成日志可区分。
- [ ] 当前认知状态不冒充历史轮次快照；材料查看与状态轮询不启动、不恢复、不清理任务。
- [ ] 文件阅读限制在明确允许的材料根目录，拒绝越界和原始 HTML 执行；引用原件无需复制成重复材料。
- [ ] 保留必要的主题、响应式、键盘操作与可访问性行为；尚未接入的新控制不暴露可误触的旧操作。
- [ ] 使用同一新格式和接口提供 demo；浏览器测试贯通真实后端与运行子进程，验证角色、实时输出、材料阅读和失败现场，不以虚假活动替代集成。
