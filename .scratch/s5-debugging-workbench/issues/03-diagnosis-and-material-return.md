**Status:** resolved

实施与测试共同遵循 [S5 规格](../spec.md)，本票验收重点如下。

- [x] 检查查询绑定所选运行、Attempt 和 Call，默认最近相关调用并支持历史选择；错误和必要输入输出来自保存的那一次调用，拒绝跨运行/无关调用，不用最新输入重建历史。
- [x] 详情区串起阻塞原因、Worker 错误及必要交接，区分传入材料与已记录工具动作；缺失输入明确不可用，不声称展示模型隐藏上下文。
- [x] 任务材料按已登记用途、归属及内容类型进入允许清单；打开绑定的任务版本或受限工作文件，旧版本不可取得时提示不可用，不静默读取当前工作树，不另存完整源码快照。
- [x] 复用有界只读内容和可信渲染能力；任务链接、下载、工具提示及隐藏详情都不能绕回证据、审计、哈希或内部检验材料。任务测试命令和必要错误可读，混合内部报告不作为通用原件展示。
- [x] 中央文件阅读返回后恢复工作、调用、筛选、滚动位置和焦点；长内容局部滚动，键盘/Escape 与快速切换可靠。
- [x] 复用 S4 的用户产出及完成/未完成原因；工作成功、运行关闭和交付完成分别表达，不展开审核轨迹、主张版本历史或重新生成检查报告。
- [x] 经真实 HTTP 和浏览器演示阻塞到原件再返回；覆盖两次不同输入的重试、无关调用拒绝、旧材料缺失、内容链接边界、刷新和焦点恢复。此票不依赖实时活动查询。
