# 03: 通过 L0／L1 阅读并控制探索专题

**What to build:** 研究者从专题目标、认知小节和最新轮次的原文摘录进入完整材料，继续查看附件和证据链接，并使用所有既有研究控制操作。用真实专题即可演示，不依赖新 Provider 或结构化事件。

**Blocked by:** None (can start immediately).

Status: ready-for-agent

**规格：** [Research Workbench 与多 Provider 执行](../spec.md)。本票交付 L0／L1 与阅读、控制和视觉规则；L2 的结构化事件由 04、05 交付，期间保留现有原始日志阅读入口。

- [ ] L0 展示专题导航、目标与认知小节摘录、轮次预算和最新轮在前的探针／结果卡片；未提交结果不得显示为轮次成功。
- [ ] Observer 和界面共同落实父规格的标题／正文长度、Objective 优先、STATE 小节、截断和空内容规则；明确区分缺失与空白，标注原文摘录，不生成 AI 摘要或历史快照。
- [ ] 点击材料打开 L1，完整阅读目标、状态、探针、结果、反馈、既有进展材料和实验附件；原始日志仍可访问。
- [ ] Markdown 证据链接、长文分段、代码高亮和材料路径复制可用，保持现有工程材料访问边界，不扩大对私有运行文件的访问。
- [ ] 分开展示研究状态、当前活动、最近错误和断点等待；保留 unknown，空闲的 IN_PROGRESS 不播放运行动效，不以错误文本推断失败或将停止混同于失败。
- [ ] 停止、继续、追加轮数、断点调试和方向意见重拟均可通过新界面操作；完成专题不可重开，预算耗尽需追加，重拟后再次停下且不增加轮次。
- [ ] 未启用控制与演示模式保持只读；材料读取不反向改变研究状态。
- [ ] 轮询更新保留组件身份、材料滚动位置、焦点和展开态，状态改变不自动打开抽屉；不依赖强制重挂载或伪造定时器。
- [ ] 桌面尺寸、明暗令牌、零位移悬停、抽屉过渡、关闭时不可交互和减少动态效果规则符合父规格；窄屏不溢出，导航可收起，键盘关闭后焦点返回入口。
- [ ] 复用真实 HTTP 服务与浏览器链验收摘录、证据导航、控制操作和阅读稳定性，覆盖运行、空闲、断点及失败状态；通过构建和类型检查。测试使用本票开工时有效的配置，不把 01 的配置迁移作为前提。
- [ ] 如复用第三方代码或资产，保留相应许可声明；不引入新的前端状态管理或布局框架。
