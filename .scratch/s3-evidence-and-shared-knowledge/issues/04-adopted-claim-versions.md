# 04: 采用版本的声明与交接

**What to build:** 工作安排和实际结果明确记录采用了哪条主张的哪个版本，用户能够追溯判断依据，材料被读取本身不构成采用。

**Blocked by:** 03 — 按问题查询与授权展开。

**Status:** ready-for-agent

依据：[S3 规格](../spec.md)。本项登记并读取采用引用；依据修订后的再判断由事项 05 完成。

- [ ] Expert 在已有工作安排中显式声明依赖的主张版本，Engine 检查身份、版本与授权并保留到实际工作交接。
- [ ] Designer 在已有结果回传中补充执行时另行采用的主张版本，保存为实际依据，不覆盖最初派发上下文，不增加单独报告。
- [ ] 材料被传入或通过工具读取但没有采用声明时，不自动生成采用引用，也不声称理解正确。
- [ ] 历史工作、结果及只读观察能定位实际采用版本并展开对应依据；重复恢复不重复登记同一采用声明。
- [ ] 无主张采用的工作仍按既有流程运行；无效版本、身份或越权引用被明确拒绝，不静默改为当前版本。
- [ ] 通过 Engine 与脚本化 Worker 验证查询后显式采用、仅阅读未采用、Designer 补充引用以及恢复后的引用可追溯；测试观察实际交接和结果。
