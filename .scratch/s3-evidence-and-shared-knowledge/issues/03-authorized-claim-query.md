# 03: 按问题查询与授权展开

**What to build:** Expert 和 Designer 能从各自工作入口查找需要的主张，按需读取详情与原件，清楚知道条件、反证、缺项及读取范围。

**Blocked by:** 01 — 主张登记与反馈分析贯通。

**Status:** claimed

依据：[S3 规格](../spec.md)。本项基于已登记主张提供查询，不依赖修订冲突流程或采用声明。

- [ ] 复用成果访问路径，支持已有身份、主张三态和问题文本筛选，采用简单筛选及文本查找，不增加向量服务或自动相关性评分。
- [ ] 每条查询结果带适用条件、已登记关键反证或未决提示、来源入口；筛选 `supported` 不裁掉该条关联反证。
- [ ] 摘要可继续展开详情和原件，查询范围、省略、未展开、来源缺失及访问失败可辨；不用固定最近历史条数或无提示截断代替选择性读取。
- [ ] Expert 初始入口可发现当前 Task 的主张索引及待处理反馈；Designer 获得本次工作、固定输入和指定材料，并可在授权范围继续查询。
- [ ] 角色与任务权限约束查询和原件读取，共享可读不授予覆盖权限；跨 Task 未声明依赖或未授权的材料不能读取。
- [ ] 提示词只补入口、查询方法、覆盖及输出约定，不要求固定阅读顺序、数量或每轮必调工具；观察出口复用相同事实且保持只读。
- [ ] 从 Worker 实际交接驱动查询，结合既有成果读取、工具权限及观察出口测试验证筛选、展开、缺项与拒绝访问，不绑定内部存储布局或完整提示词快照。
