# 01: 主张登记与反馈分析贯通

**What to build:** Expert 在已有反馈分析中按需登记主张，下一次交接和只读入口能够看到其判断、条件及依据；工作结果和待处理反馈不会因中断丢失。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

依据：[S3 规格](../spec.md)。本项先贯通已持久保存证据上的首次登记与读取；后续事项补修订、检索和临时原件保留。

- [ ] 反馈分析与持续主张分开；一次分析可不新增主张或登记多条主张，一条主张可引用多次工作。保留现有反馈字段语义，不强制改名。
- [ ] Expert 的登记建议经 Engine 检查后持久保存主张身份、初始版本、所属任务、明确陈述与范围、三态判断、理由及必要证据、反证或未决项；非法状态、无效身份及越权写入被拒绝并说明原因。
- [ ] 结构化状态沿用现有账本，证据引用既有原件，Markdown 与只读观察入口消费同一来源；不产生第二份权威状态或独立报告。
- [ ] 下一次 Expert 交接及已有只读出口可按身份看到主张与来源；新结果未分析时保留当前判断并提示相关待处理结果，而非自动改变三态。
- [ ] 已处理反馈允许对应 `unresolved`；未提交有效分析、仅声明已读或调用失败不能清除反馈，一次调用不必处理全部反馈。
- [ ] 用既有 Engine 运行与恢复夹具验证登记、实际上下文、观察结果和结果保存后中断；确认恢复保留反馈与原件，既有无主张工作仍可正常运行。
