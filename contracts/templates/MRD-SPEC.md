# 用户 → Ge：任务输入模板

用户可以交文档或自然语言；无需手填所有 JSON。Ge 负责抽取，下列缺口分为“必须由用户决定”和“可由专家调查”。Winson 的建议作为材料引用，不直接形成运行授权。

## MRD：为什么做

- 想解决的问题 / 当前瓶颈：
- 最终给谁用 / 什么决策会使用结果：
- 本轮成功是什么：
- 不做什么：
- 已有代码、论文、数据、参考结果和版本：
- 重要取舍（速度、面积、精度、工程成本等优先级）：

## SPEC：何时算完成

- 交付物（代码、脚本、报告、原始数据等）：
- 必须保持的接口、数值语义和兼容性：
- 必须通过的测试 / 独立参考：
- 比较对象、工作负载、指标、单位、聚合方式：
- 允许的结论等级（功能 / 解析模型 / 仿真 / 综合 / 实测）：
- 可改目录 / 冻结目录 / 允许工具与网络：
- 实验次数、总时长、模型费用与审核预留：
- 停止条件 / 达不到目标时交付什么：
- 需要研究的未知项：
- 必须由我决定的未决事项：

## Ge 返回的任务确认卡

1. 我理解的目标与范围；逐条对应原文位置。
2. 将交付什么、用什么证据验收、能声称什么。
3. 任务与依赖、先做哪个最小实验；这是执行计划，不需要用户逐命令批准。
4. 总预算与停止规则；已经授权的范围直接执行。
5. 明确假设和真正阻塞的决定；不能把缺失预算填成无限。
6. TaskSpec ID/revision/hash；现有授权覆盖情况。

本模板本身不授权费用、发布、真实设备操作或扩大读取范围。
