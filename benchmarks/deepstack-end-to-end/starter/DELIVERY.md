# 最低交付口径

覆盖：整体流程/架构、硬件层次、工作负载/并行映射、调度/tiling、主要模块成本及组合、性能输出/设计空间评价；自主选择代表性链路深入核对。

结果入口为 `results/README.md` 或等价短索引：主要结论、成立条件、关键反例/失败与未决项，链接单项详情、重放命令、输入/版本及原始数据。小交付可以合并，不要求固定报告数或实验次数。

核心主张必须有匹配强度的证据，区分原文描述、源码事实、实际运行和推断；模块存在不代表已接入主链路。说明竞争解释和观测不能区分的地方。外置验收由操作者按这些公开要求复核，重放关键证据，不以文档字数或自报完成评分。

允许保留范围外变体、无法取得的校准来源、不可见内部公式和尚不能唯一判别的细节，但要解释已知接口、影响范围和证据限制。关键流程未解释、可读实现未追踪、矛盾未处理，不能仅标未知而通过。无法观察部分若阻断核心要求，则如实交付未完成/受阻结果。模型行为证据不自动证明真实硬件准确性。
