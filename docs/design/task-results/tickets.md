## 字段归属与接口决定

| 信息 | 唯一来源 | 消费方式 |
| --- | --- | --- |
| 稳定任务成果入口 | task.json 的可选 `results_path`，项目相对 Markdown 路径 | 跨 revision 显式沿用同一路径；旧合同无字段保持原行为 |
| 引擎实验身份 | plan 的可选 `experiment_id` | 同一任务内稳定，跨 run 沿用；缺失显示未关联 |
| 引擎执行、计划、解释 | ledger、原有 plan/context/evaluation/report | README 自动区是可重建投影，键为 run/attempt，不复制原件 |
| 外部批次关联 | README 固定登记区的一条批次引用 | 键为 external/batch-id；原有 index 只引用，项目专用格式不改写；无伪造 run |
| 原件、分析、累计结论 | 原批次/index/specs | README 人工区摘要与显式链接，生成器保留该区 |
| 审核对象 | 现有 promotion/report.json | 保存实际提供的成果文本、来源摘要及版本；测量缓存键仍独立 |

自动区使用固定 JSON 注释保留关联并生成表格，二者在同一 README 内由同一次原子写入维护；无第二份 JSON 文件。外部批次通过 CLI 参数登记，不要求临时请求文件。显式 Markdown 链接只读取项目或 artifact_root 内的允许材料；不递归扫描目录。上下文预算内保存实际正文及来源摘要，未展开项明确标识。审核保存实际消费文本，摘要不冒充内容存储。
